แบบฝึกปฏิบัติ: HTML Link และ Image

เรียนรู้การสร้างลิงก์และการแทรกรูปภาพด้วยแท็ก HTML
พร้อมตัวอย่างและการตกแต่งด้วย CSS

⛓️ ตัวอย่างลิงค์ (link example)

ผลลัพธ์
ไปยังเว็ปไซต์มหาวิทยาลัย เปิด Google ในแท็บใหม่ 💌 ส่งอีเมล์ถึงผู้สอน ←กลับไปหน้าแรก
Code HTML
  1. <a href = "https://www.npru.ac.th" > เว็บไซต์มหาวิทยาลัย </a>
  2. <a href = "https://www.google.com" target = "_blank" > เปิด Google ในแท็บใหม่ </a>
  3. <a href="mailto:teacher@example.com">ส่งอีเมล</a>
  4. <a href="index.html">กลับหน้าแรก</a>

✉️ ตัวอย่างรูปภาพ (Image example)

ผลลัพธ์
Code HTML
  1. <img src = "images/campus.jpg" alt = "ภาพมหาวิทยาลัย" width = "220" >
  2. <img src = "images/student.jpg" alt = "นักศึกษากำลังเรียน" width = "180" >
  3. <img src = "images/logo.png" alt = "โลโก้วิชา" height = "80" >

💘จุดประสงค์การเรียนรู้

1อธิบายการใข้งานแท็ก <a> เพื่อสร้างลิงก์ไปยังหน้าเว็บหรือแหล่งต่างๆ

2 แทรกรูปด้วยแท็ก <img> พร้อมกำหนดคุณสมบัติพื่้นฐาน

3 ตกแต่งลิงก์และรูปภาพด้วย <CSS> เพื่อความสวยและน่าใช้งาน

ส่งไฟล์ HTML พร้อมไฟล์และรูปภาพ

i

เกร็ดความรู้

แท็ก <a> ใช้สำหรับสร้างลิงก์ (Hyperlink) เพื่อเชื่อมโยงไปยังหน้าเว็บ ไฟล์ หรือที่อยู่ข้อมูลต่าง ๆ โดยใช้แอตทริบิวต์ href ระบุปลายทางของลิงก์ แท็ก <img> ใช้สำหรับแทรกรูปภาพ โดยใช้แอตทริบิวต์ src ระบุแหล่งที่อยู่ของไฟล์รูปภาพ และ alt ระบุข้อความอธิบายรูปภาพ ซึ่งสำคัญต่อการเข้าถึง (Accessibility) และช่วยเมื่อรูปภาพไม่สามารถโหลดได้

CSS สามารถใช้ตกแต่งลิงก์ด้วยตัว link color เอฟเฟกต์เมื่อ hover ขนาดของรูปภาพ ขอบ border มุมโค้ง border-radius และเงา box-shadow และอื่น ๆ เพื่อให้หน้าเว็บมีความสวยงามและใช้งานง่ายขึ้น
